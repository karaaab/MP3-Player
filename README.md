# MP3-Player
A small, portable MP3 player device using the YX5300 Serial MP3 Player board, SSD 1306 display, and Arduino Nano. It is currently a work in progress.
I am using the YX5300_ESP32 library from bluejunimo, which is under MIT licensing. The original file may be found [here](https://github.com/bluejunimo/YX5300_ESP32).
